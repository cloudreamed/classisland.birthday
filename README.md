# 同学生日板（ClassIsland 插件）

在主界面显示今天过生日的同学；今天没有人过生日时，显示距离最近一次生日的倒计时。
插件版本 **1.2**，作者 **zepher**。

## 组件行为

- **今天有人过生日**：显示 `今日生日：张三、李四`。
- **今天没人过生日**：显示最近一次生日的倒计时，例如 `王五 还有 5 天过生日`。
- **倒计时超过上限**：可在设置里限定「最近生日超过 N 天就不显示」。超过上限时**整个组件隐藏**，不占位置。
- **名单为空**：显示 `尚未录入生日名单`。

## 生日的记录方式（v1.2 起）

每个同学记录：**姓名 + 公历出生日期（年/月/日）+ 按哪种历法过生日**。

- 日期框里填的**永远是公历出生日期**。
- 后面的 `0/1`（设置界面里的「公历/农历」下拉框）表示**按哪种历法过生日**：
  - `0` / 公历：以后每年按**公历的月-日**过。
  - `1` / 农历：用出生年份把公历生日换算成**农历月-日**，以后每年按这个农历月-日过。
- 闰月一律按**普通月**处理（例如闰二月出生按二月过）。
- 平年遇到 2/29 按 2/28 处理。

## 维护名单

在组件设置里可以：

- **添加/删除**：手动增删同学；年/月/日通过下拉框选择，避免滚轮误改。
- **倒计时上限**：设置「最近生日超过 N 天就不显示」，`0` 表示不限制。
- **从 txt 导入**：每行一条，推荐格式：

  ```
  张三 2008年3月6日 0
  李四 2009年11月12日 1
  ```

  - 末尾的 `0/1`：`0`=公历，`1`=农历；省略时按 `0`（公历）。
  - 也兼容旧格式（无年份、无 0/1）：`张三 3月6日`，按公历、年份未知处理。
  - 导入为**追加**，并按「姓名 + 年 + 月 + 日 + 历法」自动去重。
  - txt 请使用 **UTF-8** 编码保存。

## 使用

1. 在 ClassIsland 主界面进入编辑模式，从组件列表添加「生日」。
2. 打开该组件的设置，手动录入或从 txt 导入名单。
3. 字号、颜色、背景等沿用组件通用设置。

## 构建与打包

```bash
dotnet build -c Release
# 若本机没有 pwsh（只有 Windows PowerShell），追加参数：
# dotnet build -c Release -p:PowershellBinaryName=powershell
```

产物 `.cipx` 可：

- 在 ClassIsland「设置 → 插件 → 从本地安装插件」中选择安装；或
- 放入数据目录的 `Cache/PluginPackages/` 后重启，自动解包安装。
